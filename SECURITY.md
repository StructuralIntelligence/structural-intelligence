# Security Policy

## Supported Versions

The Structural Intelligence repository is maintained as a living knowledge and publishing project.

The current public repository version is supported.

Archived, downloaded, forked, or historical copies may not reflect the latest updates, corrections, revisions, or published materials.

## Reporting a Vulnerability

If you discover a security issue involving:

- Repository access
- Account compromise
- Unauthorized modifications
- Exposed credentials
- Website integrations
- GitHub repository security

Please report it privately to:

contact@structuralintelligence.llc

Please include:

- A description of the issue
- Steps to reproduce the problem
- Screenshots or supporting evidence, if available

Security reports will be reviewed as promptly as possible.

Please do not publicly disclose security vulnerabilities until they have been investigated and addressed.

## Scope

This policy applies to:

- Structural Intelligence GitHub repositories
- Structural Intelligence documentation
- Structural Intelligence website integrations
- Structural Intelligence publishing infrastructure

This policy does not apply to third-party platforms, services, applications, or repositories not owned or controlled by Structural Intelligence LLC.
